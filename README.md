# p2p-core Cloudflare relay

The relay source and setup guide live in [p2p-core/cloudflare](https://github.com/KakkoiDev/p2p-core/tree/main/cloudflare). Use that directory for new deployments and updates.

This repository contains the initial standalone setup. Existing deployments can switch to the source in p2p-core using the same Worker name and Cloudflare account.
